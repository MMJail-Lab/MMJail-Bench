# Responsible use

MMJailBench supports safety research, controlled adversarial evaluation, and reproducible comparison of multimodal models. Benchmark prompts and responses may include unsafe, offensive, or sensitive content.

Use evaluation resources in controlled research environments. Apply the relevant model/provider terms, avoid deploying generated harmful material, and protect credentials and personal information in logs and reports.

This initial public repository contains evaluation code, taxonomy metadata, and aggregate results. Dataset access terms and sensitive-material handling will be documented with the later dataset release. Raw response-level failure examples and credentials should not be posted in public issues.

Benchmark performance is specific to the evaluated models, inputs, decoding settings, and judge. It is not a general safety certification. The benchmark-specific judge is not validated as a universal safety arbiter.

For a removal request or a reproducibility issue, open an issue containing only a non-sensitive description and the relevant record identifier. Sensitive evidence can be shared through a mutually agreed private channel.
